What Gateway Deliberately Rejects

Preserved Invariants & Architectural Non-Responsibilities
  • Zero Database Connections (ADR-005): Contains NO SQL or ScyllaDB drivers, NO connection pools, and connects to NO persistent data store.

  • No Stateful Business Logic: Operates completely statelessly, enabling instantaneous horizontal scaling and rolling restarts.

Ed25519 Digital Signatures

-x^2 + y^2 = 1 - (121665/121666) x^2 y^2

Defined over finite field F(2^255 - 19). Projective coordinates (X:Y:Z:T) eliminate modular divisions. Signature (R, S) is 64 bytes, validated without secret keys.

Twisted Edwards · Curve25519 · RFC 8032

Argon2id Hybrid Hashing

m=65536 KiB (64 MB), t=3, p=4

First half of pass 1 uses Argon2i (data-independent memory access) to resist side-channels; remaining passes use Argon2d (data-dependent) to defeat GPU/ASIC crackers.

SK = KDF(DH_1 || DH_2 || DH_3 || DH_4)

DH_1 = (IK_A, SPK_B), DH_2 = (EK_A, IK_B), DH_3 = (EK_A, SPK_B), DH_4 = (EK_A, OPK_B). Delivers mathematical forward secrecy and cryptographic deniability.

Core Scheduling Architecture & Deficit Round Robin

Production memory topology of BoundedDeliveryScheduler: global preemption for SOS distress beacons, per-device DRR fairness, and drop-to-durable backpressure.

⚡ emergency_queue_ (Global Shared) Strict Preemption

ONE global queue for ALL devices. 1,000 dedicated reserved slots. SOS distress signals cut all lines and preempt round-robin execution immediately, dispatching to worker threads with sub-millisecond priority.

🔄 per_device_queues_ (1 Per Device) Max 50 Tasks / Dev

std::unordered_map<DeviceId, deque<DeliveryTask>>. Each recipient device has its own isolated FIFO queue. Urgent packets (ACKs, session ratchets) precede Normal bulk chatter inside the queue.

🎡 active_device_ring_ (DRR Fair Ring) Quantum = 5 Tasks

Maintains active non-empty devices. Worker threads process up to 5 tasks per turn per device. Once a device reaches its quantum, it yields to the back of the ring, preventing chatty group floods from starving quiet direct chats.

🛡️ Drop-to-Durable Backpressure Zero RAM Exhaustion

If a device queue hits 50 tasks or global memory ceiling hits 10,000 tasks, excess envelopes spill safely to ScyllaDB pending_deliveries_by_device outbox with zero dropped packets and bounded memory.
