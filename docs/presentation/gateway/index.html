What Gateway Strictly Owns

Stateless Perimeter Defense & Ingress Translation
  • TLS 1.3 Termination & Cleartext Redirection: Mandatory HTTP 308 upgrade on :8080 with HSTS preload; strict AEAD cipher enforcement on :8443.
  • Perimeter Identity Header Stripping: In-place erasure of untrusted headers (x-user-id, x-scopes, x-device-id) before routing.
  • Token Verification & Fast-Fail: Bearer token extraction, 2s local LRU cache lookup, and mTLS session validation with Auth Service.
  • Coarse Scope & Assurance Evaluation: Route-level OAuth2 scope matching and MFA requirement checking (Primary vs MFA-verified).
  • Workload Bulkheading & Circuit Breaking: Isolated concurrency pools preventing file transfers from starving auth/health requests; Nygard FSM breakers.
  • Streaming Bounded Buffers & Integrity: Max 4 MiB chunks with 8 MiB memory ceiling, dual CV backpressure, and constant-time SHA-256 validation.
✗

What Gateway Deliberately Rejects

Preserved Invariants & Architectural Non-Responsibilities
  • Zero Database Connections (ADR-005): Contains NO SQL or ScyllaDB drivers, NO connection pools, and connects to NO persistent data store.
  • Zero Object Storage Direct Access: Never interacts directly with MinIO or S3; chunk persistence is delegated entirely to Files Service over mTLS.
  • No Cryptographic Token Authority: Does not issue tokens, does not hold private signing keys, and does not store credentials (Auth owns authority).
  • Zero Decryption Keys or Plaintext (ADR-008): Never possesses identity keys, signed prekeys, ratchet states, or symmetric file keys. Ciphertext is opaque octets.
  • No Fine-Grained Domain Authorization: Does not check group memberships, room rosters, or file ACLs (respective backend services own fine-grained checks).
  • No Stateful Business Logic: Operates completely statelessly, enabling instantaneous horizontal scaling and rolling restarts.

Ed25519 Digital Signatures

-x^2 + y^2 = 1 - (121665/121666) x^2 y^2

Defined over finite field F(2^255 - 19). Projective coordinates (X:Y:Z:T) eliminate modular divisions. Signature (R, S) is 64 bytes, validated without secret keys.

Twisted Edwards · Curve25519 · RFC 8032

Argon2id Hybrid Hashing

m=65536 KiB (64 MB), t=3, p=4

First half of pass 1 uses Argon2i (data-independent memory access) to resist side-channels; remaining passes use Argon2d (data-dependent) to defeat GPU/ASIC crackers.

Memory-Hard · RFC 9106 · Zero Timing Leaks

Signal X3DH 4-Way Agreement

SK = KDF(DH_1 || DH_2 || DH_3 || DH_4)

DH_1 = (IK_A, SPK_B), DH_2 = (EK_A, IK_B), DH_3 = (EK_A, SPK_B), DH_4 = (EK_A, OPK_B). Delivers mathematical forward secrecy and cryptographic deniability.
